⚠️ TURNOVER / REVENUE UNIT CONVERSION — CRITICAL (Japanese companies) ⚠️
Japanese companies (and others) commonly report Revenue / Turnover in BILLION units
(e.g., "14,662.6 Bn JPY", "900.3 bn JPY"). The Guide unit for MT0 (Turnover) is
"Million in reported currency".

Conversion formula:
  Bn JPY → JPY Million = stated figure × 1,000
  (because 1 Billion = 1,000 Million)

CORRECT EXAMPLE:
  Report: "Revenue FY March 2025: 14,662.6 Bn JPY"
  ANSWER = 14,662.6 × 1,000 = 14,662,600   ← CORRECT ✓

INCORRECT EXAMPLE (do NOT do this):
  Multiplying by 1,000,000 → 14,662,600,000  ← WRONG (this is JPY, not JPY million)
  Or using any non-rounded intermediate step → 14,662,620  ← WRONG ✗

SELF-CHECK: The result must equal the source number × 1,000 exactly, with no
additional digits introduced. If your ANSWER has more significant figures than
the source number × 1,000, recompute.

CONTEXT must show the verbatim source figure and arithmetic, e.g.:
  "Revenue FY March 2025: 14,662.6 Bn JPY × 1,000 = 14,662,600 JPY Million"

### ⚠️ JAPANESE / ASIAN ENERGY UNIT CONVERSION RULE — CRITICAL ⚠️
Japanese and some Asian companies commonly report electricity/energy in units of
"hundred million kWh" (億kWh) or "10,000 MWh" (万MWh). These are NOT standard SI
prefixes and must be converted carefully:

  1 hundred million kWh  =  1 × 10^8 kWh
                          =  1 × 10^5 MWh
                          =  100 GWh

Therefore:
  X hundred million kWh  →  X × 100  GWh     ← USE THIS WHEN GUIDE UNIT IS GWh
  X hundred million kWh  →  X × 100,000  MWh

CORRECT EXAMPLE (Guide unit = GWh):
  Report: "87.4 hundred million kWh"
  GWh = 87.4 × 100 = 8,740 GWh
  ANSWER = 8740   ← CORRECT ✓

INCORRECT EXAMPLE (do NOT do this):
  Report: "87.4 hundred million kWh"
  Multiplying by 100,000 → 8,740,000
  ANSWER = 8740000  ← WRONG — this is MWh, not GWh ✗

SELF-CHECK: After converting "hundred million kWh" to GWh, the result should be
  X × 100 (two orders of magnitude, not five). If your ANSWER is five or more
  orders of magnitude larger than the source number, you have converted to MWh
  instead of GWh — recompute.

Similarly, when a source reports in "万MWh" (10,000 MWh units):
  X 万MWh  →  X × 10,000 MWh  →  X × 10  GWh

CONTEXT must always show the full arithmetic, e.g.:
  "87.4 hundred million kWh × 100 = 8,740 GWh"

⚠️ PIPE ESCAPE RULE — CRITICAL ⚠️
The CONTEXT column often contains table rows, formulas, or values from source documents
that include the pipe character "|". Every pipe character inside ANY cell — especially
CONTEXT — MUST be replaced with the HTML entity &#124; BEFORE writing the row.

EXAMPLES OF CORRECT PIPE ESCAPING IN CONTEXT:
  Source table:  "Gross Scope 1 GHG emissions | 16,057,222.7 t CO2e"
  CONTEXT cell:  Gross Scope 1 GHG emissions &#124; 16,057,222.7 t CO2e

  Source table:  "Total renewable energy | 851,268.1 MWh"
  CONTEXT cell:  Total renewable energy &#124; 851,268.1 MWh

FAILURE MODE TO AVOID:
  ✗ WRONG:  ... | Gross Scope 1 GHG emissions | 16,057,222.7 | 16,057,222.7
     (The unescaped pipe creates a phantom 15th column; page number is lost)
  ✓ RIGHT:  ... | Gross Scope 1 GHG emissions &#124; 16,057,222.7 | 12
     (Pipe escaped; exactly 14 columns; page number lands correctly)

COLUMN COUNT SELF-CHECK (mandatory per row, internal and silent):
After composing each row, count the pipe characters. There must be exactly 13 pipes
(= 14 columns). If you count 14 or more pipes, you have an unescaped pipe inside a
cell. Find it, replace it with &#124;, and recount before emitting.

### ⚠️ RATIO DIRECTION RULE — FEMALE TO MALE (DERV_BC05) ⚠️
When the metric is named "Ratio of Female to Male Board Members" (or equivalent), the
formula is:

  ANSWER = Number of Female Board Members ÷ Number of Male Board Members

CORRECT EXAMPLES:
  Female = 6, Male = 10  → ANSWER = 6 ÷ 10 = 0.6   ← Female minority → result < 1 ✓
  Female = 4, Male = 3   → ANSWER = 4 ÷ 3 = 1.33   ← Female majority → result > 1 ✓

INCORRECT EXAMPLE (do NOT invert):
  Female = 4, Male = 3
  ANSWER = 3 ÷ 4 = 0.75  ← WRONG — this is Male÷Female, not Female÷Male ✗

SELF-CHECK: The formula is always Female ÷ Male, regardless of which group is larger.
  - When females are the minority (Female < Male): result will be < 1.0 — CORRECT.
  - When females are the majority (Female > Male): result will be > 1.0 — ALSO CORRECT.
  - Only flag an error if the denominator is Male and the numerator is Female, and the
    arithmetic was reversed. Do NOT assume > 1.0 is always wrong.

Similarly, any metric named "X to Y ratio" means X ÷ Y (numerator = X, denominator = Y).
Always confirm the ordering of the ratio matches the metric name before recording the
ANSWER.

### ⚠️ BINARY / QUALITATIVE METRICS: NO vs NA — CRITICAL ⚠️
The same logic applies to Binary (Yes/No) metrics:

- ANSWER = NA when the topic is ABSENT from the report (not mentioned, not addressed).
- ANSWER = No ONLY when the report EXPLICITLY states the practice/policy/certification
  does NOT exist, has been abandoned, or is explicitly scoped out.
- NEVER use "No" as a default when you searched and found nothing — that is NA.

COMMON FAILURE MODES TO AVOID:
  ✗ WRONG: Report does not mention ISO 27001 certification → ANSWER = No
  ✓ RIGHT: Report does not mention ISO 27001 certification → ANSWER = NA

  ✗ WRONG: No biodiversity investment policy found → ANSWER = No
  ✓ RIGHT: No biodiversity investment policy found → ANSWER = NA

  ✗ WRONG: No water management commitment found → ANSWER = No
  ✓ RIGHT: No water management commitment found → ANSWER = NA

ANSWER = No IS VALID only when the source explicitly states, e.g.:
  "We do not hold ISO 27001 certification"
  "No separate Risk Committee exists at the Board level"
  "No biodiversity fund or investment policy is in place"

This rule applies to ALL qualitative metrics regardless of whether they are Base or Derived.
For Derived qualitative metrics where inputs are absent → ANSWER = NA (not "Not Computable"
and not "No"). "Not Computable" is reserved for quantitative derived metrics only.

### ⚠️ PR01 / PR02 / DERV_PR03 — ABSENT TOPIC RULE: NA NOT No ⚠️
When the report contains NO mention of physical climate risk monitoring, adaptation
results, or quantification of physical climate impacts:
→ ANSWER = NA (NOT No)
"No" is ONLY valid when the report explicitly states "we do not monitor physical climate
risks" or equivalent direct negation of the metric predicate.

ALSO VALID FOR Yes: A statement that the company HAS evaluated, assessed, or analysed
physical climate risks (even if concluded non-material) IS evidence of monitoring/
assessment activity. A disclosed risk assessment, CRVA, or materiality evaluation that
COVERS the topic → ANSWER = Yes for the assessment/monitoring metric.

TYPICAL WRONG "No" TRIGGERS TO REJECT:
  ✗ "No explicit monitoring indicators are disclosed" → ANSWER = NA
  ✗ "No quantitative projected costs disclosed" → ANSWER = NA
  ✗ "No indicators related to monitoring are disclosed" → ANSWER = NA

CASCADES: When PR01 = NA (topic absent from report), DERV_PR03 must also be NA —
not No. A derived metric cannot be No when its inputs are absent.

AFFIRMATIVE VERB OVERRIDE RULE (applies to PR01 and all monitoring metrics):
When the source contains an affirmative monitoring verb ("closely monitors",
"tracks", "assesses", "reviews", "evaluates") alongside uncertainty language

CORRECT: "the Company closely monitors climate change adaptation and associated

INCORRECT: Returning No because of "uncertainties" language → WRONG ✗

### 9A. METRIC-PREDICATE ALIGNMENT AND EVIDENCE ENTAILMENT — CRITICAL

Before assigning any ANSWER, silently rewrite the metric as a precise testable predicate:
"Does the source explicitly disclose [required action/status/value] for [required subject/scope]?"
Then evaluate ONLY evidence that answers that predicate.

MANDATORY RULES:
1. Match the evidence to the metric's exact subject, action, scope and time period.
2. Do not use a nearby sentence merely because it contains the same topic word.
3. A negative conclusion about MATERIALITY does not negate the existence of an analysis,
   assessment, dependency, policy, location review or other disclosed activity.
4. Distinguish these questions:
   - "Is biodiversity material?" may be No.
   - "Did the company analyse biodiversity/ecosystem dependencies?" is Yes when an analysis is disclosed.
   - "Did the company perform a biodiversity location analysis?" is Yes when a location analysis is disclosed.
5. If the report contains both a negative materiality conclusion and positive evidence of an
   analysis/activity, answer according to the metric being asked. Never allow the negative
   materiality sentence to override positive evidence for a different predicate.
6. CONTEXT must contain the strongest verbatim passage that directly entails the ANSWER.
   A sentence that only mentions the topic but does not prove the metric is invalid evidence.

BINARY ENTAILMENT DECISION:
- Yes = explicit positive evidence that the required practice/activity/status exists.
- No = explicit evidence that the required practice/activity/status does not exist or was not done.
- NA = no evidence that proves either Yes or No.
- "Not material", "below threshold", or "no material impacts" is NOT automatically No.
  It is No only when the metric itself asks whether the topic/impact is material.

BIODIVERSITY EXAMPLES — APPLY GENERALLY:
- Source: "Bechtle has also analysed the dependencies on ecosystem services..."
  Metric asks whether ecosystem-service dependencies were analysed -> ANSWER = Yes.
- Source heading/text: "Location analysis in relation to biodiversity" and disclosure of the
  location screening -> Metric asks whether a biodiversity location analysis was performed
  -> ANSWER = Yes.
- Source: "It was thus established that biodiversity is not a material issue..."
  This supports No only for a biodiversity-materiality metric. It does NOT support No for
  dependency analysis, location analysis, risk screening, or assessment-existence metrics.

## 10. GOVERNANCE COMMITTEE VALIDATION
Two-step, and existence is NEVER inferred from independence counts:

STEP 1 — Existence: The committee must be EXPLICITLY named (e.g., "Audit Committee",

         • Committee is explicitly NOT maintained / responsibility sits elsewhere
           (e.g., "no separate Risk Committee; overseen by the Audit Committee / full Board")
           → member count = NA AND existence-derived = No. Do NOT record 0.
         • Committee simply not mentioned → count = NA, existence = NA.

INDEPENDENCE COUNT — SHAREHOLDER REPRESENTATIVE TRAP:
A statement that a committee "consists solely of shareholder representatives"
or "consists of shareholder-elected members" does NOT establish the independence
count. "Shareholder representative" describes how a member was elected, not
whether they are independent of the company under governance definitions.

If the report names committee members but does NOT explicitly state how many
are "independent" (using that word or a defined equivalent like "independent
non-executive"), apply Section 10.1 first. If Section 10.1 does not apply:
  → independence count = NA  (never 0 by inference)

0 is ONLY valid when the report explicitly states the committee has zero
independent members, or when the named members are each explicitly labelled

  AI produces: ANSWER = NA  ← CORRECT — independence status not disclosed

### 10.1 BUSINESS-APPROVED INDEPENDENCE PROPAGATION RULE
When ALL of the following are true:
(a) the committee is explicitly named;
(b) every committee member is explicitly listed or the total committee size is explicit;
(c) the report explicitly states that 100% / all members of the relevant shareholder group are independent;
(d) no named committee member is explicitly labelled non-independent;
then treat the disclosed committee membership as independent and set:
Independent committee members = total named committee members.

For Bechtle-style disclosures, apply this approved interpretation to the named Supervisory Board
committees when the report states that all shareholder-group members fulfil the independence
criterion and separately provides the complete committee membership:
- Audit Committee: five named members -> ANSWER = 5 unless the report explicitly identifies a
  committee member as non-independent.
- Nomination Committee: three named members -> ANSWER = 3 unless the report explicitly identifies
  a committee member as non-independent.

CONTEXT must include BOTH:
1. the verbatim independence statement; and
2. the verbatim committee membership statement/list.
PDF PAGE INDEX must include all printed pages used. Do not return NA merely because the report
presents independence at parent-board/shareholder-group level rather than repeating it in the
committee table.

### ⚠️ SECTION 10.1 APPLICATION GATE — ALL CONDITIONS MUST BE EXPLICITLY MET ⚠️
Before applying the independence propagation rule, verify ALL of these are EXPLICITLY stated:
(a) The committee is EXPLICITLY named ✓
(b) EVERY committee member is EXPLICITLY listed by name OR total size is explicitly stated ✓
(c) The report EXPLICITLY states that 100% / ALL members of the relevant shareholder-group
    ARE independent — using the word "independent" or a defined governance equivalent ✓
(d) No named committee member is explicitly labelled non-independent ✓

If ANY condition is not explicitly met → independence count = NA. Do NOT apply 10.1 when:
  - Independence is stated for the full Supervisory Board as a combined % but not traced to
    the specific committee's membership individually
  - The % given refers to a different population than the committee members
  - The committee member list is not explicitly provided in the report

VOLKSWAGEN-STYLE CAUTION: A statement "X% of the Supervisory Board are independent" does
NOT automatically propagate to individual committees (Audit, Nomination) unless the report
EXPLICITLY states that all members of THAT SPECIFIC COMMITTEE are independent.
If independence for the specific committee is not explicitly confirmed → NA.

⚠️ NEVER assign Scope 1 and Scope 2 values based on their relative magnitude.
The correct assignment is ALWAYS determined by the SOURCE LABEL in the table or text,
regardless of which figure is larger.

COMMON FAILURE MODE (Japanese / pharmaceutical companies):
  Scope 1 (direct combustion) is often SMALLER than Scope 2 (purchased electricity).
  Example: Scope 1 = 50,600 tCO2e, Scope 2 = 3,300 tCO2e — the larger value IS Scope 1.
  A model that assumes "larger = Scope 1" will swap these, producing cascading errors
  in DERV_M07 (% Scope 1) and DERV_M08 (% Scope 2).

MANDATORY RULE: Read the row/column LABEL in the source table first.
  If the label says "Scope 1" → that value is M01. Period.
  If the label says "Scope 2" → that value is M02. Period.
  Do NOT substitute a size-based assignment when a label is present.

SELF-CHECK: After populating M01 and M02, verify:
  - The CONTEXT for M01 explicitly contains the word "Scope 1" adjacent to the value.
  - The CONTEXT for M02 explicitly contains the word "Scope 2" adjacent to the value.
  - If neither CONTEXT contains the matching label, you have mis-assigned — recheck.

CASCADE: DERV_M07 = M01 ÷ DERV_M10 × 100 and DERV_M08 = M02 ÷ DERV_M10 × 100.

M04 (Net Zero Target Year) — SCENARIO ALIGNMENT RULE  [NEW]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

When a company states its GHG reduction targets are "aligned to" or "consistent with"
a named net zero pathway that has an explicit target year, that target year IS the
company's net zero target year → M04 = that year.

ACCEPTED EVIDENCE (each alone is sufficient):
  ✓ "Our targets are aligned to the IEA Net Zero Emissions by 2050 scenario" → 2050
  ✓ "Committed to net zero by 2050 in line with the Paris Agreement" → 2050
  ✓ "Science-based targets aligned to a 1.5°C pathway by 2040" → 2040
  ✓ "We target net zero Scope 1+2 emissions by 2035" → 2035
  ✓ Any sentence where the company's OWN targets reference a specific year as the
    net zero / carbon neutral endpoint

REJECT (scenario reference without company commitment):
  ✗ "The IEA NZE 2050 scenario assumes global emissions reach net zero by 2050"
    (reporting what the scenario says, not stating the company is committed to it)
  ✗ "We use the IEA NZE scenario for stress-testing" (analytical use, not a target)

KEY TEST: Is the company declaring ITS OWN targets to be aligned with / aimed at /
committed to net zero by [year]? If yes → M04 = that year.

CORRECT:
  "We constructed our 2030 portfolio targets aligned to the IEA's Net Zero Emissions
   by 2050 scenario" → M04 = 2050 ✓
  (The company's own targets are explicitly aligned to the NZE 2050 pathway;
   2050 is the disclosed endpoint of that commitment.)

INCORRECT:
  Returning NA because the word "target" does not appear immediately next to "2050" ← WRONG ✗

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
QAF-SPECIFIC / GENERAL OVERRIDE — DERV_M12 PATH 2 MANDATORY EXECUTION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

DERV_M12 FAILURE MODE TO CORRECT:
The most common error is: M05 = NA → model returns DERV_M12 = NA without
executing PATH 2. This is ALWAYS wrong when the report discloses annual GHG emissions data.

MANDATORY PATH 2 TRIGGER: If the report discloses:
  • A single-year GHG disclosure combined with ANY stated GHG reduction target or
    commitment (even qualitative, e.g., "we aim to reduce emissions") — the combination
    of measurement + stated direction = monitoring system, OR
  • Any narrative stating the company "monitors", "tracks", "measures", or "reports"
    its GHG emissions (even for a single year) alongside a reduction intent or target year.
NOTE: A single year of GHG data with NO reduction target and NO monitoring language does
NOT automatically trigger Yes. The data alone must be accompanied by either (a) a
multi-year time series, OR (b) a stated reduction target or commitment.
  • Annual Scope 1 and/or Scope 2 GHG figures for multiple years (e.g., a time-series
    table showing 2022, 2023, 2024 emissions), OR
  • Any GHG data table with year-over-year comparison, OR
  • Any stated GHG intensity metric tracked annually (e.g., tCO2e/SGD million as a KPI), OR
  • Any narrative stating the company "closely monitors", "tracks", or "measures"
    its GHG emissions or carbon footprint over time —
  → DERV_M12 = Yes (PATH 2 is satisfied).

INCORRECT (forbidden):
  M05 = NA → DERV_M12 = NA  ← WRONG when multi-year GHG data is disclosed ✗
CORRECT:
  M05 = NA → search SR for multi-year GHG table → found → DERV_M12 = Yes ✓

--- ENERGY ---

- Energy → "energy consumption", "SECR", GWh table

- Energy Intensity (DERV_EC09) → search SR first for "energy intensity",
  "MWh per", "GWh per", "energy consumption per revenue", or any
  energy/revenue ratio table. The SR typically reports this in its
  ESRS/GRI energy table. Only fall back to AR if completely absent in SR.
  When the SR reports in MWh/kEUR and Guide unit is GWH/Revenue, convert:
  MWh/kEUR = GWh/million EUR (same numeric value, different label).
  Show conversion in CONTEXT: "X MWh/kEUR = X GWh/million EUR"

- Non-Renewable Energy (EC02) → DERIVATION PERMITTED when not explicitly stated:
  If the report discloses Total Energy Consumption AND Renewable Energy Consumption
  but does NOT separately state non-renewable consumption, compute:
  Non-Renewable Energy = Total Energy − Renewable Energy
  Convert all values to GWh before subtracting (TJ ÷ 3.6 = GWh).
  SOURCE = SR, CONTEXT must show: "Total Energy [X GWh] − Renewable Energy [Y GWh] = [Z GWh]"
  Search synonyms: "non-renewable", "fossil", "grid electricity", "purchased electricity"
  NOTE: Once EC02 is populated, DERV_EC06 (Share of Non-Renewable) MUST be computed:
  DERV_EC06 = EC02 ÷ DERV_EC05 (Total Energy) × 100

- DERV_EC06 (Share of Non-Renewable Energy) — COMPLEMENT RULE:  [NEW]
  When EC07 (Share of Renewable Energy Consumption) is explicitly reported as a percentage,
  DERV_EC06 = 100 − EC07, regardless of whether EC01 or EC02 are individually populated
  in absolute GWh terms.

  CORRECT examples:
    EC07 = 100% → DERV_EC06 = 0%  ✓
    EC07 = 29.9% → DERV_EC06 = 70.1%  ✓
    DERV_EC07 derived = 14% → DERV_EC06 = 86%  ✓

  Do NOT return Not Computable for DERV_EC06 when EC07 (or DERV_EC07) is populated
  or derivable, even when EC01 and EC02 individual GWh figures are not separately stated.
  CONTEXT must show: "100% − Renewable Share [X%] = [Y]% non-renewable"

  PRIORITY: If EC02 is directly stated in GWh → use EC02 ÷ DERV_EC05 × 100 (higher priority).
  If EC02 is not stated but EC07 / DERV_EC07 is known → apply 100 − EC07.

- EC01 / EC02 — RENEWABLE % RATE OVERRIDES LABELED SUBTOTALS — CONFLICTING DATA RULE:  [NEW]
  When the report contains BOTH:
    (a) A directly labeled "renewable electricity consumed" figure in GWh on one page, AND
    (b) A total energy figure + renewable energy share % on a different (often more detailed)
        data appendix or GRI/ESRS table page,
  apply the CONFLICTING DATA MOST AUTHORITATIVE PAGE RULE (see Section 11 Waste):
    Priority 1: GRI/ESRS/GHG appendix data table with total energy + % renewable breakdown
    Priority 2: Narrative or subsidiary-level explicitly labeled GWh subtotal
  CORRECT approach when both exist: EC01 = Total Energy (GWh) × Renewable Share (%)
  CONTEXT must note when this override applies:
    "Multiple disclosures found; used [page X] total × % as most authoritative.
     Labeled subtotal on [page Y] was [Z GWh] but overridden by total [T GWh] × [P%]."
  SELF-CHECK: EC01 + EC02 must equal DERV_EC05. If they do not, the values are
  inconsistent — recheck source selection before emitting.

- DERV_EC08 (Commitment to Renewable Energy) — EXPLICIT COMMITMENT REQUIRED:
  ANSWER = Yes when the report explicitly discloses a COMMITMENT, target, pledge,
  programme, or active adoption initiative related to renewable energy — such as:
    "We are committed to 100% renewable electricity by 2030"
    "RE100 member" / "committed to renewable energy procurement"
    "Power Purchase Agreement (PPA) for renewable energy"
    "We have set a target to source X% of energy from renewables"
    "We are gradually introducing renewable energy sources in its properties"
    "We are adopting renewable energy sources" (active, ongoing adoption programme)
    Any statement that the company IS ACTIVELY INTRODUCING or ADOPTING renewable
    energy as part of its environmental/GHG reduction strategy.

  A high share of renewable energy (e.g., 78% or 79%) in the data table alone does NOT
  by itself constitute a commitment. However, a narrative statement describing ACTIVE
  INTRODUCTION or ADOPTION of renewable energy sources (even without a % target)
  DOES constitute a commitment when framed as an ongoing or planned initiative.

  ANSWER = NA when renewable energy is consumed but the report contains ONLY data tables
  with no narrative commitment, adoption statement, or forward-looking initiative language.
  ANSWER = No ONLY when the report explicitly states no renewable energy commitment exists.

  ⚠️ CARBON NEUTRALITY TARGETS ≠ RENEWABLE ENERGY COMMITMENT:
  A company's carbon neutrality goal, net-zero target, or SBTi-certified Scope 1/2
  reduction target does NOT constitute a commitment to renewable energy.

  ACCEPT only explicit renewable energy-specific commitments:
    ✓ "RE100 member" / "We are committed to 100% renewable electricity by [year]"
    ✓ "We have signed Power Purchase Agreements (PPAs) for renewable energy"
    ✓ "We have set a target to source X% of energy from renewables by [year]"
    ✓ "We will procure all electricity from renewable sources by [year]"

  SELF-CHECK: Does the evidence contain the words "renewable energy" or "renewable
  electricity" AND a forward-looking commitment verb (committed, target, pledge, procure)?
  If the evidence is only about carbon neutrality, GHG reduction, or SBTi targets
  WITHOUT a specific renewable energy sourcing/procurement pledge → ANSWER = NA.

--- WASTE ---

- Waste totals → "disposed", "recycled or recovered", "hazardous", "non-hazardous" (chart labels)

- W04 (Non-Hazardous Waste) & W05 (Hazardous Waste) → CHART/BAR GRAPH EXTRACTION RULE:
  When a waste bar chart shows stacked or grouped bars labelled "Hazardous" and
  "Non-hazardous" with printed numeric labels on the bars (e.g., "93" and "230"),
  those ARE P3 explicit values and MUST be extracted.
  Do NOT return NA on the grounds that values "are not explicitly reported" when the
  same page contains a labelled chart showing the breakdown.
  Read numeric labels off bar charts; apply unit from chart title (e.g., kt → ×1,000 tonnes).
  CORRECT: Chart shows "Hazardous 93 kt" and "Non-hazardous 230 kt" → W05 = 93,000 mt, W04 = 230,000 mt
  INCORRECT: Returning NA because no prose sentence states the figure separately.

- Non-Hazardous Waste Total (W04) → MULTI-ROW AGGREGATION RULE:
  When a waste table breaks non-hazardous waste across multiple disposal/recovery
  categories (e.g. "preparation for reuse", "recycling", "other recovery", "landfill",
  "other disposal"), the total non-hazardous waste is the SUM of the non-hazardous
  sub-rows across ALL categories — NOT the figure from any single row.
  CORRECT approach: sum ALL "of which non-hazardous waste" rows across the table.
  INCORRECT approach: reading only the first "non-hazardous" row encountered.
  CONTEXT must show the full arithmetic: "Non-haz reuse [X] + Non-haz recycling [Y]
  + Non-haz landfill [Z] + Non-haz other disposal [W] = Total [sum]"

- Total Recycled Waste (W02) → COMPOSTING EXCLUSION RULE:
  "Recycled waste" means material that is processed into new materials or products.
  COMPOSTING is classified as "other recovery" — NOT recycling — unless the report
  EXPLICITLY labels composting as recycling.

  MANDATORY CHECKS for W02:
  1. Include: items explicitly labelled "recycled", "recycling", "sent for recycling",
     "material recycling", "WEEE recycled".
  2. EXCLUDE by default: "sent for composting", "composted", "organic recovery",
     "anaerobic digestion" — unless the report's own definition section explicitly
     states these count as recycling.

- Total Recycled Waste (W02) → DERIVATION FROM TOTAL × RECYCLING RATE% PERMITTED:
  Reports sometimes disclose total waste tonnage AND a recycling rate % but NO explicit
  recycled tonnage figure. In this case, DERIVATION IS PERMITTED:
    W02 (Recycled Waste) = Total Waste (mt) × Recycling Rate (%)
  CONDITIONS that must ALL be met before computing:
    (a) Total waste tonnage is explicitly printed
    (b) Recycling rate % is explicitly stated in the same report
    (c) No explicit recycled tonnage figure appears anywhere in the document
  SOURCE = SR, CONTEXT must show the full arithmetic:
    "Total Waste [6,658 mt] × Recycling Rate [54.0%] = 3,595.32 mt recycled"
  Once W02 is computed this way:
    → DERV_W08 = W02 value (since W01 Reused = NA)
    → W03 (Non-Recycled) = Total Waste − W02 = 6,658 − 3,595.32 = 3,062.68 mt

  ⚠️ PRIORITY RULE: A directly stated recycled tonnage (P1/P2/P3) ALWAYS overrides
  this derivation. Only use Total × Rate% when no explicit tonnage exists.

- DERV_W08 (Total Recycled & Reused Waste) — NON-METRIC UNIT CONVERSION RULE:  [NEW]
  When the report discloses waste diverted, recycled, or reused in non-metric units
  (e.g., pounds/lbs, short tons, kilograms) but does NOT separately state the volume
  in metric tonnes, convert to metric tonnes before populating W02 and DERV_W08:
    Pounds (lbs) → metric tonnes: lbs ÷ 2,204.62
    Short tons → metric tonnes: short tons × 0.907185
    Kilograms → metric tonnes: kg ÷ 1,000
  CONDITION: Only when no explicit metric-tonne figure is separately disclosed.
  CONTEXT must show the full conversion arithmetic:
    "Waste diverted [2,839,175 lbs] ÷ 2,204.62 = 1,287.841 metric tonnes"
  Do NOT return Not Computable when a convertible weight in non-metric units is
  explicitly disclosed. Unit conversion is NOT estimation — it is deterministic arithmetic.
  SELF-CHECK: If the report contains any weight figure for recycled/diverted waste in
  any unit, convert it before returning Not Computable for DERV_W08.

- Total Recycled Waste (W02) → DERIVATION PERMITTED:
  If W01 (Reused) = NA AND W02 (Recycled) is populated, DERV_W08 = W02 value.
  "Not Computable" only applies when BOTH W01 and W02 are NA.
  CONTEXT must note: "W01 Reused [NA] + W02 Recycled [X mt] = [X mt]"

- Total Non-Recycled Waste (W03) → DERIVATION PERMITTED when not explicitly stated:
  If the report discloses Total Waste Generated AND Total Recycled/Recovered Waste
  but does NOT give a separate "non-recycled" total figure, compute:
  Non-Recycled Waste = Total Waste Generated − Total Recycled & Recovered
  SOURCE = SR, CONTEXT must show: "Total Waste [X mt] − Recycled/Recovered [Y mt] = [Z mt]"
  ⚠️ CRITICAL: Do NOT use "landfill" tonnage alone as a proxy for total non-recycled waste.

- Total Recycled & Reused Waste (DERV_W08) → SINGLE-INPUT FALLBACK:
  If W01 (Reused) = NA AND W02 (Recycled) is populated, DERV_W08 = W02 value.
  "Not Computable" only applies when BOTH W01 and W02 are NA.
  CONTEXT must note: "W01 Reused [NA] + W02 Recycled [X mt] = [X mt]"

- CONFLICTING DATA — MOST AUTHORITATIVE PAGE RULE:
  When a report contains the same metric on multiple pages with different values:
  PRIORITY ORDER:
  1. GRI/ESRS/SASB labelled data table (highest authority)
  2. Sustainability performance data appendix / data table section
  3. Narrative in body text
  4. Summary table / highlights section (often rounded or selective)
  When values conflict: use the DETAILED DATA TABLE value over summary/highlights.
  CONTEXT must note: "Multiple disclosures found; used [page X] value from [table name]
  as most detailed/authoritative source". Record ALL pages in PDF PAGE INDEX.

--- WATER ---

- Total Water Consumption (DERV_WC08) → CONSUMPTION vs WITHDRAWAL DISTINCTION:
  ⚠️ Water CONSUMPTION and water WITHDRAWAL are DIFFERENT metrics — never substitute one for the other.
  Water Withdrawal = total water taken in from all sources (always the LARGER number).
  Water Consumption = withdrawal minus wastewater discharged = water not returned to environment.
  ALWAYS search for and use the "total water consumption" figure, NOT "water withdrawals".
  Search specifically: "total water consumption", "water consumed", "net water use".
  NEVER use "water withdrawal" or "water withdrawals" when "water consumption" is
  separately stated in the same document.
  If WC01 (Direct Water Consumption) is populated AND WC02 (Indirect) = NA,
  DERV_WC08 = WC01 value. Do NOT return Not Computable when one valid input exists
  and the other is explicitly NA.
  CONTEXT must note: "WC01 [X m³] + WC02 [NA] = [X m³]"

- Water Reduction Target % (WC04) → EXPLICIT TARGET RULE:
  Search for the stated % target in "Our 2025 water target" or equivalent target box.
  If the report states "To be 20% towards water positive by 2025", ANSWER = 20, not NA.
  A target framed as "X% towards water positive" IS a quantitative reduction target.
  When the metric asks for a % reduction target and the CONTEXT already contains
  a verbatim sentence with an explicit % figure (e.g. "reduced by 30%"), the ANSWER
  must be that % number (30), not NA.

⚠️ WC04 (Water Reduction Target %) — DIRECT OPERATIONAL TARGET ONLY:  [NEW]
WC04 requires a quantitative target for the company's OWN OPERATIONAL water
consumption reduction — expressed as a % reduction vs a baseline year or
absolute reduction target for the company's own facilities/operations.

REJECT as WC04:
  ✗ Supply chain or sourcing targets (e.g., "X% of ingredients sourced from
    sustainable water management areas by [year]") — this is a PROCUREMENT TARGET
  ✗ Product water-efficiency targets (e.g., "X% reduction in water used per product")
  ✗ External/customer water targets or industry ambitions

ACCEPT only:
  ✓ "Reduce our own operational water consumption by X% by [year]"
  ✓ "Cut water use in our stores/factories/facilities by X%"
  ✓ "Achieve X% reduction in water intensity across our operations"

SELF-CHECK: Does the target measure the company's DIRECT water consumption reduction
in its OWN facilities? If not → ANSWER = NA.

- Water Recycled & Reused (WC05) — EXACT METRIC REQUIRED:
  WC05 requires water that has been RECYCLED or REUSED within operations — NOT water
  withdrawn, consumed, or discharged.
  ONLY accept values explicitly labelled:
    "Water recycled", "water reused", "recycled water volume", "water recirculation"
  REJECT: Total water withdrawn, total water consumption, water discharged, non-potable water used.
  If the report reports only water withdrawn or consumed → WC05 = NA.

- Water Intensity / Water per Turnover (DERV_WC09) → UNIT FLEXIBILITY RULE:
  Some reports state water intensity in litres/euro (or L/€) rather than m³/Revenue.
  When the SR explicitly reports a water intensity figure (e.g. "0.03 l/€"), use that
  directly as ANSWER. UNIT must reflect what the report states: "Litre/Euro" or "L/€".
  Do NOT return Not Computable if DERV_WC08 is Not Computable but the report
  directly discloses a water intensity ratio — a P1 reported value overrides derivation.
  Search: "water intensity", "water consumption per revenue", "l/€", "litre per euro",
  "m³ per million EUR"

⚠️ DERV_WC09 (Water per Turnover) — DENOMINATOR MUST BE REVENUE:  [NEW]
The denominator for DERV_WC09 is ALWAYS Turnover / Total Revenue (SL 1, MT0)
expressed in reported currency million — NOT production volume, NOT operating profit,
NOT any physical output measure.

MANDATORY DENOMINATOR CHECK:
Before computing DERV_WC09, confirm the denominator is:
  ✓ Total Revenue / Net Sales / Turnover in currency million (from income statement)
  ✗ Production volume (tonnes, units, batches) — WRONG
  ✗ Operating profit / EBITDA / net income — WRONG
  ✗ Any physical quantity (MWh produced, products sold) — WRONG

SELF-CHECK: The unit of DERV_WC09 must be m³/[currency] million (e.g., m³/KRW million,
m³/USD million). If your unit contains a physical measure (e.g., m³/tonne,
m³/product), you have used the wrong denominator — recompute using MT0 (revenue).

CORRECT: Water Consumption [m³] ÷ Revenue [KRW million] = m³/KRW million ✓
INCORRECT: Water Consumption [m³] ÷ Production [tonnes] = m³/tonne ✗

When the SR reports a water intensity figure in non-revenue units (e.g., m³/tonne of
product), do NOT use that figure for DERV_WC09. Instead compute:
Water Consumption [DERV_WC08 or WC01] ÷ Turnover [MT0, SL 1].

- DERV_W12 (Total Waste Generated / Turnover Intensity) — DENOMINATOR CURRENCY SCALE RULE:  [NEW]
  DERV_W12 = Total Waste Generated (metric tonnes) ÷ Turnover (SL 1, MT0, in reported
  currency MILLION). The GUIDE unit is metric tonnes / Revenue in currency million.

  ⚠️ BILLION-DENOMINATION DENOMINATOR TRAP — CRITICAL:
  Some reports state waste intensity already computed, but express it per currency BILLION
  (e.g., "47.2 tons per KRW billion in revenue"). This is NOT the correct unit.
  The Guide requires per currency MILLION. When a source figure uses billion as denominator:

  Conversion: Reported figure (per billion) ÷ 1,000 = Correct figure (per million)
  Because: 1 billion = 1,000 million → intensity per billion is 1,000× smaller per million.

  CORRECT EXAMPLE:
    Source: "Waste intensity: 47.2 tons per KRW billion in revenue"
    ANSWER = 47.2 ÷ 1,000 = 0.0472  metric tonnes / KRW million  ✓

  INCORRECT EXAMPLE (do NOT do this):
    Source: "47.2 tons per KRW billion"
    ANSWER = 47.2  ← WRONG — this is per billion, not per million ✗

  Alternatively: compute directly from Total Waste (mt) ÷ Turnover (KRW million):
    e.g., 3,248 mt ÷ 103,134,500 KRW million = 0.0000315 mt/KRW million

  SELF-CHECK: If the reported intensity figure is a round number like 47.2 and your
  denominator is a billion-scale currency, you have almost certainly not applied the
  ÷1,000 conversion — recompute. The correct answer per currency million will be
  1,000× smaller than the figure stated per billion.

  CONTEXT must show verbatim source intensity AND full arithmetic:
    "Waste intensity [47.2 tons per KRW billion] ÷ 1,000 = 0.0472 metric tonnes / KRW million"
  or
    "Total Waste [X mt] ÷ Turnover [Y KRW million] = Z metric tonnes / KRW million"

- DERV_WC07 (Initiatives to Reduce Fresh Water Consumption) → BROAD SEARCH RULE:
  Any disclosed initiative, programme, or achievement of freshwater reduction qualifies.
  Search: "reduced freshwater withdrawals", "water efficiency", "water recycling",
  "water replenishment", "brackish water", "water management plan", "water positive".
  If ANY such initiative is found → ANSWER = Yes.

- DERV_WC10 (Commitment to Water Management) → DERIVATION FROM TARGET:
  If WC04 is populated (i.e., an explicit water target exists), ANSWER = Yes.
  Also: any explicit water reduction programme constitutes a commitment → Yes.
  ANSWER = NA only when NO water target, programme, or initiative is mentioned anywhere.

⚠️ DERV_WC10 (Commitment to Water Management) — TWO-PATH EVALUATION:
DERV_WC10 must NOT return NA simply because WC04=NA. Like DERV_M12,
this metric is independently checkable by definition.

PATH 1 — WC04 SHORTCUT:
If WC04 is populated (explicit % reduction target) → DERV_WC10 = Yes immediately.

PATH 2 — DIRECT DEFINITION CHECK (required when WC04 = NA):
Search the full report for ANY of the following:
  (a) Any stated water efficiency commitment, target, or initiative
  (b) Any narrative stating the company aims to "improve water efficiency", "reduce water use"
  (c) A water management policy or framework
  (d) A named water programme or water stewardship initiative
  (e) Any water-related KPI with a forward-looking improvement target

CORRECT:
  WC04 = NA AND report states "improve average energy and water efficiency by 50% by 2035"
  → DERV_WC10 = Yes (PATH 2: water efficiency commitment found) ✓

ANSWER = NA only when BOTH WC04 = NA AND no water commitment of any kind appears anywhere.

--- BIODIVERSITY & ENVIRONMENT ---

- EMS/ISO 14001 — CERTIFICATION vs ASPIRATION — CRITICAL DISTINCTION:
  ANSWER = Yes ONLY when the report explicitly states the company IS CERTIFIED or HAS
  an operational EMS in place — past tense completion or present-tense active certification.
  ANSWER = NA when the company describes steps, plans, or programmes TOWARD future certification.
  The key test: Has certification been ACHIEVED and is currently HELD?

  ⚠️ EHS POLICY / INTERNAL SAFETY PROGRAMME ≠ CERTIFIED EMS — CRITICAL:
  REJECT: "EHS Policy", "Health and Safety Management System", "Environmental policy",
          "We conduct EHS audits" without explicit ISO 14001 / EMAS language.
  ACCEPT: Explicit "ISO 14001 certified" / "ISO 14001 certification" / "EMAS registered"

  SELF-CHECK: Before answering Yes, verify the words "ISO 14001" or "EMAS" appear
  verbatim in the evidence. If they do not, ANSWER = NA.

- Land Use Footprint → "land occupied/used", "operational footprint", "hectares used/disturbed"
  (EXCLUDE restoration/reforestation/biodiversity project hectares)

- BD03 (Commitment to Biodiversity) — SPECIFICITY REQUIRED:
  ANSWER = Yes ONLY when the report explicitly discloses a commitment SPECIFICALLY to
  biodiversity — such as:
    "We are committed to protecting biodiversity"
    "Our biodiversity policy...", "We target net positive biodiversity impact"
    "Member of [biodiversity initiative]", "No net loss of biodiversity commitment"
  ANSWER = NA when evidence is ONLY general environmental stewardship without naming biodiversity.
  The word "biodiversity" or an explicit nature/ecosystem commitment must appear.

DERV_BD05 (Monitoring of Biodiversity) — BROAD EVIDENCE RULE  [NEW]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ANSWER = Yes when the report discloses ANY of the following:
  (a) Wildlife habitat protection near operations or office locations
  (b) Biodiversity surveys, assessments, or screening at operational sites
  (c) Ecosystem protection, conservation, or restoration programmes
  (d) Land use monitoring near sensitive ecological areas
  (e) Partnerships with conservation organisations for site-level monitoring
  (f) Any disclosure of action taken to protect wildlife, habitats, or ecosystems
      at or near the company's operational locations

  (Rationale: "protecting wildlife habitats near our office locations" is an

INCORRECT:
  Returning NA because no explicit "biodiversity monitoring programme" is named ← WRONG ✗

Search anchors: "wildlife habitat", "wildlife habitats", "ecosystem", "conservation",
  "habitat protection", "species", "nature", "ecological", "biodiversity near",

--- HEALTH & SAFETY ---

- Rate of Recordable Work-Related Injuries (H01) → UNIT CONVERSION RULE:
  Many reports state injury frequency rate per 1,000,000 hours worked (not per 20,000).
  The Guide unit is per 20,000 hours. Conversion formula:
  Rate per 20,000 hrs = Rate per 1,000,000 hrs × (20,000 ÷ 1,000,000) = Rate × 0.02
  EXAMPLE: 0.23 per 1,000,000 hrs × 0.02 = 0.0046 per 20,000 hrs
  Search synonyms: "frequency rate", "lost-time injury frequency rate", "LTIFR",
  "recordable injury rate", "accidents per million hours"
  CONTEXT must show verbatim rate from source + conversion arithmetic.

  ANSWER = Yes if the report discloses ANY formal health and wellbeing programme,
  health hub, mental health support, or wellbeing platform for employees.
  Search: "health and wellbeing", "regional health hubs", "employee assistance programme",
  "wellbeing hub", or any named wellbeing platform (e.g. "Thrive@bp").
  "Not Computable" is ONLY valid if H01 AND H02 are BOTH NA AND no health programme exists.

- DERV_H08 (Commitment to Working Conditions - Wages and Hours) → YES WHEN POLICY EXISTS:

  "working conditions", "collective bargaining".

    ✓ "Suppliers are assessed against our Supplier Code of Conduct"
    ✓ "Third-party ESG assessments of suppliers were completed for X% of supply spend"
    ✓ "Supplier self-assessment questionnaires on ESG criteria were administered"

  SUPPLIER (selling something to the company) or a CLIENT (buying from the company)?"

    ✓ A named Sustainable Sourcing Policy or Responsible Procurement Policy
    ✓ A supplier code of conduct that includes environmental/social sustainability criteria
    ✓ An explicit commitment to sourcing from certified sustainable suppliers
    ✓ A stated target for sustainable/ethical sourcing as % of procurement spend
    ✓ Membership in sustainable procurement initiatives with documented sourcing standards

  REJECT as SS02=Yes:
    ✗ General environmental compliance language without a sourcing-specific framework
    ✗ Compliance with environmental regulations (EPA, local health depts) that covers
      waste disposal/operations but not PROCUREMENT/SOURCING decisions
    ✗ A statement that facilities have environmental policies covering their own operations
    ✗ A supplier code of conduct that covers only labour/human rights without sustainability criteria

--- HUMAN CAPITAL ---

- Training Hours per FTE (H05) → MULTI-COLUMN TABLE RULE:
  Reports frequently break training hours into sub-columns by gender or employee category.
  Correct extraction order:
  P1: Look for an explicitly reported TOTAL or GROUPWIDE average hours per employee.
      If found, use it directly.
  P2: If only gender/category breakdowns are given with TOTAL HOURS per column:
      ANSWER = SUM(all column total hours) ÷ total average employee headcount.
  P3: If only per-column averages are given (no column totals, no groupwide headcount):
      ANSWER = NA.
  NEVER use the per-column (per-gender) average as the groupwide answer.

- H04 (Employee Turnover Rate) — VOLUNTARY DEPARTURE vs RETIREMENT DISTINCTION:  [NEW]
  H04 requires the EMPLOYEE TURNOVER RATE — the rate at which employees leave
  (voluntarily or involuntarily) as a percentage of total headcount, covering all
  forms of departure (resignation, dismissal, redundancy, retirement combined).
  REJECT as H04 evidence:
    ✗ "Total retirement rate" — retirement is a specific subset, not comprehensive turnover
    ✗ "Pension separation rate" or any rate defined only as retirements
    ✗ A rate explicitly labelled as retirement/pension separation in the source
  ACCEPT:
    ✓ Explicitly labelled "employee turnover rate", "attrition rate",
      "voluntary separation rate", "total attrition" covering all departures
    ✓ A retention rate where turnover = 100% − stated retention %
      (e.g., "79% retention → 21% turnover" is acceptable)
  ANSWER = NA when the only disclosed figure is explicitly a retirement/pension rate,
  not a comprehensive turnover or attrition rate.
  SELF-CHECK: Does the source text use the word "retirement" or "pension separation"
  to describe the disclosed rate? If so → reject and return NA.

- Gender Pay Gap Ratio (HC04) → DEFINITION PRECISION:
  This metric requires the GENDER PAY GAP expressed as a ratio or %.
  A "Men to Women Earnings Ratio" or pay parity table is NOT the gender pay gap

--- GOVERNANCE ---

### ⚠️ BOARD MEMBER COUNT vs WORKFORCE COUNT — CRITICAL DISAMBIGUATION ⚠️
BC01 (Male Board Members) and BC02 (Female Board Members) require the count of BOARD OF
DIRECTORS members ONLY — not employees, not workforce, not management.

MANDATORY CHECKS before populating BC01 / BC02:
1. The number must come from a section explicitly titled "Board of Directors",
   "Supervisory Board", "Management Board", or equivalent GOVERNANCE section.
2. Board member counts are SMALL numbers (typically 5–30 total for the full board).
3. If the extracted number is > 100, it is almost certainly a workforce/employee count —
   REJECT IT and search the governance section specifically.
4. For two-tier boards (Supervisory + Executive), combine both tiers per the TWO-TIER
   BOARD RULE — but still use governance-section counts, NEVER workforce data.

SELF-CHECK: If BC01 + BC02 > 50, you have almost certainly extracted workforce data.
Re-search the board composition section before emitting.

### ⚠️ BOARD GENDER COUNT — NO INFERENCE FROM NAMES ⚠️
BC01 and BC02 MUST come from an explicit gender disclosure in the report.
NEVER infer gender from director names, pronouns, photos, or signature blocks.
If the report does not explicitly state the gender breakdown of the board → BC01 = NA,
BC02 = NA, and all derived metrics = NA / Not Computable.

### ⚠️ BOARD COMPOSITION DATA — AR FALLBACK IS MANDATORY ⚠️
For BC01, BC02, and all derived board metrics, if the SR does not disclose board
gender/composition, the AR MUST be searched before returning NA.
Do NOT return NA for board metrics without confirming the AR has been fully searched:
  - Proxy Statement / DEF 14A (US companies)
  - Corporate Governance section of the AR
  - "Directors and Officers" section

### ⚠️ BOARD % FEMALE (DERV_BC06) — TARGET vs ACTUAL DISTINCTION ⚠️
DERV_BC06 requires the ACTUAL CURRENT % of women at board level as of the reporting date.
Do NOT use a target or goal for future female representation, or management % figures.
Use ONLY the actual disclosed % or compute BC02 ÷ DERV_BC04 × 100.

### ⚠️ PERCENTAGE OF INDEPENDENT BOARD MEMBERS (BC03) — TWO-TIER CAVEAT ⚠️
When the report separately discloses independence for the Supervisory Board only
(not the Executive Board):
STEP 1 — If independence is disclosed for the COMBINED board as a single %, use it directly.
STEP 2 — If only the Supervisory Board independence % is disclosed:
  Use only the Supervisory Board independence figure, but CLEARLY note in CONTEXT that
  the figure covers Supervisory Board only.
STEP 3 — If the report explicitly states which individuals lack independence:
  Independent members = Total members − Non-independent members
  % Independent = (Independent members ÷ Total board) × 100
  Show arithmetic fully in CONTEXT.

  ANSWER = Yes ONLY when a committee is EXPLICITLY named as a "Risk Committee",
  "Risk Management Committee", "Risk and Compliance Committee", "Risk Oversight
  Committee", or a direct named equivalent whose PRIMARY mandate is risk oversight.

  REJECT as DERV_ICR09=Yes — CRITICAL AUDIT/COMPLIANCE/FINANCE COMMITTEE TRAP:
    ✗ An Audit Committee, Audit & Compliance Committee, or Audit and Control Committee
      that has risk oversight or risk management as a SECONDARY or incidental responsibility
    ✗ A Finance Committee or ESG Committee that oversees certain risk categories alongside
      other primary responsibilities
    ✗ A general Board statement that the Board oversees risk management
    ✗ Multiple committees (Finance + ESG + Audit) sharing distributed risk oversight
    ✗ An executive management team that "also handles risk" without a formal committee name
    ✗ A Risk Management Working Group that is not a formal governance committee
    ✗ Embedding risk oversight within the general governance framework description
    ✗ An executive forum that "acts as" a risk committee without being explicitly named as one
       (unless the report explicitly states "the [named body] acts as the Group Risk Committee")

  ⚠️ AUDIT COMMITTEE WITH RISK OVERSIGHT ≠ RISK COMMITTEE — CRITICAL:

  or oversight as part of their mandate. This does NOT make them a Risk Committee.
  The committee's PRIMARY NAME must be "Risk Committee" or equivalent.
  "Audit & Compliance Committee (which oversees risk)" → DERV_ICR09 = No
  "Audit and Control Committee (directly oversees risk management)" → DERV_ICR09 = No

  ACCEPT only:
    ✓ A committee whose name itself contains "Risk" as the primary identifier
    ✓ "Risk Committee", "Risk Management Committee", "Risk Oversight Committee",
      "Risk and Compliance Committee" — where "Risk" is the lead term in the name

  ANSWER = No when the report discloses full governance structures (committees listed)
  but none is explicitly named with "Risk" as its primary identifier.
  ANSWER = NA when governance structures are completely undisclosed.

  This mirrors the DERV_ICR08 (CSR Committee) rule: the committee's PRIMARY mandate
  must be risk oversight and it must be EXPLICITLY NAMED in the report.

### ⚠️ TWO-TIER BOARD STRUCTURE RULE — CRITICAL (German/European Companies) ⚠️
Many European companies have a TWO-TIER board: SUPERVISORY BOARD + EXECUTIVE BOARD.
BOTH together constitute the company's full "Board of Directors" for ESG metric purposes.

MANDATORY RULE: For all board composition metrics (BC01, BC02, DERV_BC04, DERV_BC05,
DERV_BC06, BC03), you MUST combine both boards for all headcount metrics.

CORRECT EXAMPLE (Hapag-Lloyd style):

  Executive Board:   4 male, 1 female = 5 total

  DERV_BC06 (% Female) = 6 ÷ 21 × 100 = 28.57%

CONTEXT must clearly state which boards were combined.
SELF-CHECK: If a company discloses both boards and your ANSWER for Total Board equals
only the Supervisory Board count, you have NOT combined the boards. Recount before emitting.

ISO 9001, ISO 14001, ISO 45001, ISO 50001.
ANSWER = Yes ONLY when "ISO 27001" is explicitly named in the report.
ANSWER = NA when the report mentions other ISO standards but NOT ISO 27001.

PRACTICES — NOT general whistleblowing for any misconduct.

TWO-PART SEARCH (mandatory — both steps required):

STEP 1 — CONFIRM LOBBYING IS PRESENT IN THE REPORT:
  Search the full document for: "lobbying", "political contribution", "government affairs",
  "public affairs", "advocacy activities", "lobbying register", "political engagement",
  "political action committee", "registered lobbyist".

  If ANY lobbying/political engagement content is found → proceed to Step 2.

STEP 2 — SEARCH THE WHOLE DOCUMENT FOR ANTI-RETALIATION PROTECTIONS:
  Do NOT restrict the anti-retaliation search to the lobbying section alone.
