===============================================================================
Source codes used in the metric lists (section I). Priority is ABSOLUTE — take the first

5.B  ONE-YEAR-LAG RULE (Issuer Contribution). If the Measurement Date is EXACTLY one year
     before the audit FYE, "Issuer Contribution" = employer contributions made AFTER the
     measurement date — i.e. the "contributions subsequent to the measurement date"

     RSI Schedule of Contributions and is a DISTINCT metric — keep the two separate.
     If the lag is NOT exactly one year, SKIP DEF and fall to the next source in the
     chain. Capturing the RSI contribution as Issuer Contribution when a one-year-lag DEF
     figure exists is an L6 error.

5.C  GROSS vs NET SHARE. Add the State's (or other non-employer contributing entity's)
     proportionate share ONLY when it is EXPLICITLY disclosed. If no State share is
     disclosed, gross = net. Show both operands and the sum in Context.

5.D  ACTIVITY ALLOCATION — SHARE OF NET PENSION LIABILITY OR ASSET across Governmental
     Activities, Business-type Activities, and Component Units. MANDATORY per L10 — these
     three cells are NEVER "Not disclosed" or blank when the long-term-liabilities note
     discloses the liability's activity split. Read "Liability" as "Asset" for a net asset.
     The three fractions lie in [0,1] and SUM to 1.

     TWO-STEP RESOLUTION (in order, for every plan and every activity):
       STEP 1 — USE THE DISCLOSED PROPORTION IF PRESENT. Capture it verbatim and cite it.
       STEP 2 — IF NOT DISCLOSED, CALCULATE IT. Do NOT write "Not disclosed"; do NOT leave
         blank. Show EVERY operand and result in Context:
           (i)   From the LONG-TERM LIABILITIES / CHANGES IN LONG-TERM OBLIGATIONS note,
                 read THIS plan's net pension liability/asset split into Governmental (G),
                 Business-type (B), and Total (T) for the PRIMARY GOVERNMENT.
                 gov_ratio = G/T ; bt_ratio = B/T   (these sum to 1)
           (ii)  From the pension note read THIS plan's PRIMARY-GOVERNMENT amount (PG) and
                 COMPONENT-UNITS amount (CU).
                 pg_share = PG/(PG+CU) ; cu_share = CU/(PG+CU)
                 (If the note discloses no CU amount, CU = 0 → pg_share = 1, cu_share = 0.)
           (iii) Governmental  = pg_share x gov_ratio
                 Business-type = pg_share x bt_ratio
                 Component Unit = cu_share
                 These SUM to 1.
         CONTEXT FORMAT (SYMBOLIC ONLY — substitute THIS audit's numbers; NEVER copy any
         placeholder from this prompt):
           "Note <n> split Governmental <G> / Business-type <B> / Total <T> -> gov_ratio
            <..>, bt_ratio <..>; plan PG <PG> + CU <CU> -> pg_share <..>, cu_share <..>;
            Governmental <..>; Business-type <..>; Component Unit <..>; sum 1.000000."

       STEP 2 FALLBACKS (only when the note's activity split is genuinely unavailable, in
       this order):
         (a) if the plan liability/asset is disclosed by activity in DOLLARS, proportion =
             activity amount / Total;
         (b) a public-safety-only plan = 100% Governmental; a teacher/education plan or a
             CU-only plan = 100% Component Unit;
         (c) use the plan's Deferred-Outflows or pension-expense activity split if that is
             the only split disclosed — cite the logic.
       ONLY if none of these yields a basis do you set that proportion "" per section J —
       LAST resort (L10).

     Store each proportion as a decimal fraction with FULL precision retained (e.g.
     0.8734512), never rounded in the stored Answer.
