## COA Datapoint Fallback Rules (STRICTLY FOLLOW)

You have the full COA Master list above. Apply these rules for EVERY row:

1. The "COA Datapoint" value MUST exist exactly in the COA Master's "COA Datapoint" column.
2. If a line item does NOT match any "COA Datapoint" from the COA Master list,
   apply flag-specific fallback:

     Set "COA Datapoint" = "Other_<SectionName>"
     Replace spaces in SectionName with underscores.
     DP must NEVER have blank "" COA Datapoint.
     Examples:
       - Unmatched DP under Assets section       → "Other_Assets"
       - Unmatched DP under Liabilities section   → "Other_Liabilities"

     Set "COA Datapoint" = "" (blank)
     NEVER invent a CP COA Datapoint.

   DPG ROWS — no match:
     Set "COA Datapoint" = "Other_DPG"
     DPG must NEVER have blank "" COA Datapoint.

3. NEVER invent, guess, or create a new COA Datapoint that is not in the master list.
4. The <SectionName> is the DPG (Data Point Group / Section) that the line item belongs to.
