H. COA DATAPOINT MAPPING (AUTHORITATIVE)
===============================================================================
Every row must have "COA Datapoint". Never leave blank when reliable match exists.
Map using: SOA Items (post hierarchy flattening), COA Flag, current Section, Standard COA Master.

COA MASTER FILTERING (STRICT):
FLAG FILTER: Row maps ONLY to COA Master entries with identical COA Flag. Never cross-map DPG<->DP<->CP.
STATEMENT FILTER: Only use COA Master rows where Statement = "SOA". Prefer exact match.
SECTION FILTER: Prefer matching section.

MATCHING ORDER (within same flag):
1) Mandatory mappings below  2) Full exact match  3) Case-insensitive  4) Whitespace-normalized
5) Punctuation-insensitive  6) Prefix-aware (if ":" in SOA Items, match suffix after final ":")
7) Semantic closest.  No match -> "Other_<SectionName>" (see Fallback Rule below).

MANDATORY COA MAPPINGS — DPG:
"General Revenues" -> COA Datapoint: "General Revenues"
"Transfers" -> COA Datapoint: "Transfers"
[label containing "Charges for Services" + "Governmental"] -> COA Datapoint: "Program Receipts - Charges for Services - Governmental Activities"
[label containing "Charges for Services" + "Business"] -> COA Datapoint: "Program Receipts - Charges for Services - Business-type Activities"
[label containing "Operating Grants" + "Governmental"] -> COA Datapoint: "Program Receipts - Operating Grants and Contributions - Governmental Activities"
[label containing "Operating Grants" + "Business"] -> COA Datapoint: "Program Receipts - Operating Grants and Contributions - Business-type Activities"
[label containing "Capital Grants" + "Governmental"] -> COA Datapoint: "Program Receipts - Capital Grants and Contributions - Governmental Activities"
[label containing "Capital Grants" + "Business"] -> COA Datapoint: "Program Receipts - Capital Grants and Contributions - Business-type Activities"
[label containing "Expenses" AND "Governmental" (e.g., "Expenses - Governmental Activities")] -> COA Datapoint: "Program Expenses - Governmental Activities"
[label containing "Expenses" AND "Business" (e.g., "Program Expenses - Business-type Activities")] -> COA Datapoint: "Program Expenses - Business-type Activities"
NOTE: The SOA Items value of these two DPG rows is ALWAYS the normalized fixed label ("Expenses - Governmental Activities" / "Expenses - Business-type Activities"), never the raw PDF text. The COA Datapoint is always the standardized master value.

H2. SEMANTIC FALLBACK RULES (ONLY IF NO MATCH FOUND ABOVE)
===============================================================================
Use label keywords + current Section. Evaluate in ORDER LISTED. First match wins.

GENERAL REVENUES:
GR1: (property tax|ad valorem|millage|levy|tax increment|TIF) -> "Property Taxes"
GR2: (sales tax|sales and use) -> "Sales Taxes"
GR3: (income tax) -> "Income Taxes"
GR4: (business tax|franchise tax|license tax) -> "Business Taxes"
GR5: (hotel|excise|fuel|other tax|payment in lieu) -> "Other Tax Revenues"
GR6: (intergovernmental|state aid|federal aid|grant)+(unrestricted|general) -> "Intergovernmental Revenues"
GR7: (investment|interest income|investment earnings) -> "Interest and Investment Earnings"
GR8: (gain|sale of asset|miscellaneous|other|fine|forfeiture) -> "Other General Revenues"
GR9: (transfer) -> "Transfers"

PROGRAM REVENUE: All DP rows inherit the datapoint of their DPG sub-section. No separate semantic fallback needed.

PROGRAM EXPENSES:
PE1: (general government|administration|legislative|executive|judicial|city manager|city clerk|finance|legal) -> "General Government"
PE2: (public safety|police|fire|sheriff|emergency|911|corrections|jail) -> "Public Safety"
PE3: (public works|streets|roads|highway|bridges|transportation|traffic) -> "Public Works"
PE4: (health|social service|welfare|human service|mental health|children|aging) -> "Social Services"
PE5: (education|school|library) -> "Education"
PE6: (capital outlay|capital project) -> "Capital Outlay"
PE7: (interest|fiscal charge|debt service interest) -> "Interest Expenses & Fiscal Charges"
PE8: (culture|recreation|park|arts|museum|zoo|convention|library) -> "Other Program Expenses"
PE9: (economic development|planning|community development|housing|redevelopment) -> "Other Program Expenses"
PE10: (water|sewer|electric|gas|transit|solid waste|refuse|golf|airport|marina|parking|stormwater|event center|arena|port|utility) -> "Other Program Expenses"
PE11: [default — any unmatched function] -> "Other Program Expenses"

===============================================================================
COA DATAPOINT FALLBACK RULE — "Other_<SectionName>"
===============================================================================
After exhausting ALL matching steps:
1. DP row with no match -> "COA Datapoint" = "Other_<SectionName>".
   - Under General Revenues -> "Other_General_Revenues"
   - Under Program Revenue -> "Other_Program_Revenue"
   - Under Program Expenses -> "Other_Program_Expenses"
2. NEVER leave DP COA Datapoint blank "".
3. CP rows: use "" (blank) when no master match. NEVER invent a CP datapoint.
4. DPG rows: use "Other_DPG" when no master match. NEVER blank.
COA Datapoint must never be null for any row type.
