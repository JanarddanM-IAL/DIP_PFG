H. COA DATAPOINT MAPPING (AUTHORITATIVE)
Every row must have "COA Datapoint". Never leave it blank when a reliable match exists.
Map using Row Items (post hierarchy flattening), COA Flag, current Section, Standard COA Master.

COA MASTER FILTERING (STRICT):
FLAG FILTER: Row can only map to COA Master entries with identical COA Flag. Never cross-map DPG<->DP<->CP.
STATEMENT FILTER: Only use COA Master rows where Statement = "Statement of Net Position" OR "BS". Prefer exact.
SECTION FILTER: Prefer matching section. Allow fallback only after mandatory examples and exact matches exhausted.

MATCHING ORDER (within same flag):
1) Mandatory examples below 2) Full exact match 3) Case-insensitive 4) Whitespace-normalized 5) Punctuation-insensitive 6) Prefix-aware (if ":" in Row Items, match suffix after final ":")
7) Semantic closest. Longer full-label match always wins.
 No match -> apply COA Datapoint Fallback Rule below.

H2. DETERMINISTIC COA DATAPOINT RESOLUTION
PAYROLL/PENSION ROUTING: In Liabilities section, any row containing "pension"|"opeb"|"retirement"|"post-employment"|"employee benefits" -> "Payroll Liabilities - Current" (if current/within one year) or "Payroll Liabilities - Noncurrent" (if noncurrent/after one year). Overrides "Other Liabilities" and "Long-term Debt".

RESTRICTED ASSETS PREFIX RULE (RUNS FIRST — BEFORE ALL OTHER H RULES 
INCLUDING MANDATORY MAPPINGS AND H3 FALLBACK — ASSETS SECTION):

TRIGGER: If Row Items prefix contains "Restricted" or "Temporarily restricted"
(i.e., the row is nested under a restricted assets group header per PREFIX STACK).

When triggered, IGNORE ALL OTHER RULES. COA Datapoint MUST be exactly
one of these three. Evaluate in order:

  1. "Restricted Cash and Investments"
     → if label contains (cash|investment|equity in central treasury|
       deposit|treasury|pooled cash)

  2. "Restricted Assets - Noncurrent"
     → if label contains the word "noncurrent" (exact word, case-insensitive)

  3. "Restricted Assets - Current"
     → ALL other cases — this is the DEFAULT when neither 1 nor 2 match.
       Applies to: receivables, lease receivable, lease assets, bond issuance
       costs, intergovernmental, due from, prepaid, long-term, net of 
       amortization, and anything else not matching rule 1 or 2.

HARD STOP: Do NOT evaluate any mandatory DP mapping, H2, A1–A16, or any
other rule for rows matching this trigger. The three options above are
the ONLY permitted COA Datapoints for restricted-prefix rows.

FORBIDDEN for restricted-prefix rows (override blocked):
  ✗ Accounts Receivable
  ✗ Due from Other Governments  
  ✗ Other Receivable
  ✗ Other Noncurrent Assets      ← blocks A11.5
  ✗ Other Assets - Noncurrent    ← blocks A16
  ✗ Interest Receivable
  ✗ Any other COA Datapoint not in the three options above
